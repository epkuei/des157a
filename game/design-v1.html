Chosen Game Design Sketch

A more thorough sketch my my chosen game: Copy Cat

Copy Cat is a dice placement game where strategy meets sabotage. Place your dice to build multiplying combos in each column, but matching your opponent's dice will erase theirs from that same column, so first to fill their board ends the game with the highest score winning.
